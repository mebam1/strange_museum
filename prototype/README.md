# 이상한 박물관 · 플레이어블 프로토타입

**박물관을 짓는 것이 곧 족보표를 설계하는 것.**

텍스트 게임과 브라우저 게임은 `dist/engine.js`와 `dist/catalog.js`를 함께 사용합니다. **그래픽 버전은 `dist/play.html`을 더블클릭하면 설치 없이 실행됩니다.** 텍스트 버전과 개발 서버에는 Node.js가 필요하며 별도의 패키지는 설치하지 않습니다.

## 실행

프로젝트 폴더에서:

```powershell
node cli.mjs --seed 42
node --test tests/*.test.mjs
node server.mjs
```

마지막 명령이 표시하는 주소를 브라우저로 열면 그래픽 게임을 플레이합니다. 기본 주소는 `http://127.0.0.1:4173`이며 사용 중이면 다음 포트를 선택합니다.

Windows에서는 `PLAY.cmd`를 더블클릭해도 단일 HTML 게임을 엽니다. 서버와 터미널을 유지할 필요가 없습니다. `TEXT.cmd`는 텍스트 게임을 시작합니다. 브라우저 게임은 행동마다 현재 런을 해당 브라우저에 자동 저장합니다. 브라우저가 로컬 파일의 저장을 제한하면 화면에 저장 실패를 표시하며, 이때는 개발 서버 주소에서 플레이하면 됩니다.

코드를 수정한 뒤에는 `node build-standalone.mjs`로 단일 HTML을 다시 만듭니다. 원본 모듈과 같은 엔진·카탈로그·UI를 묶으며 외부 이미지·폰트·스크립트를 요청하지 않습니다.

텍스트 게임에서는 `help`로 명령을, `catalog`로 유물 설명을, `preview`로 현재 주사위의 감동과 강화 예상을 확인합니다. 좌표는 정수이며 주사위·상품 번호는 1부터 시작합니다. 조각과 유물은 `piece free 1 2 0`처럼 선택과 동시에 배치합니다. 유물 이동은 상점에서 가능합니다.

## 플레이

1. 주사위를 클릭해 보관하고, 필요하면 나머지를 다시 굴립니다. 한 관객의 세 제출이 리롤 세 번을 공유합니다.
2. 제출하면 박물관 칸의 눈 묶음과 일치하는 원천 유물이 곱연산과 연쇄를 시작하고, 연쇄 유물이 합연산 감동을 만듭니다. 합연산 총합에 곱연산 총배율을 적용합니다. 고정 야추 점수는 없습니다.
3. 런이 계속되는 관람 종료 후 **유물 3택1**을 받습니다. **조각 3택1은 주간 평가 통과 뒤에만** 추가됩니다. 상점에서는 유물 구매·이동·판매·주사위 면 개조를 이용하며 **조각은 팔지 않습니다.** 획득물은 즉시 배치하며 무료 보상은 거절할 수 있습니다.
4. 매주 세 번째 관객은 평가 담당자입니다. 그 관객의 세 제출 합계가 기준에 도달하면 다음 주로, 미달이면 패배합니다. 8주 평가를 통과하면 클리어합니다.

## 그래픽 버전 조작과 표시

- 새 폴리오미노·유물은 **상품 카드** 또는 선택 후 나타나는 공통 **끌어서 배치** 미리보기를 박물관으로 드래그하여 놓습니다. 카드를 선택한 뒤 칸을 클릭해 배치하는 방식도 유지합니다. 배치 중 `R`로 회전하고 `Esc`로 취소합니다.
- 기존 유물은 **상점에서 드래그하여 이동**할 수 있습니다. 이미 배치한 폴리오미노는 고정이며 이동할 수 없습니다.
- 각 칸 상단에는 필요한 눈을 각각 주사위 그림으로 표시합니다. 하단의 **ΣLv**는 구성 조각의 레벨 합으로 항상 보이며, 현재 발동 횟수 **×N**과 구분합니다. 조건 미충족은 `—`, 현재 주사위 수로 완성할 수 없는 조건은 `불가`로 표시합니다.
- 조각마다 반투명 색상을 사용하며, 타일을 틈 없이 연결해 모양과 겹침을 드러냅니다. 폴리오미노를 배치하는 동안 기존 유물은 흐리게 보여 배치 상태를 함께 확인할 수 있습니다.
- 효과가 발동하면 해당 칸이 금빛으로 빛나고 유물은 회전·좌우 이동과 함께 최대 **1.1배**로 확대됩니다. 현재 연쇄에서 이미 참여한 유물에는 반투명한 검정 덮개를 표시합니다.

## 구현한 규칙

현재 규칙은 v4입니다. 감동 곱연산은 칸 반응, 감동 합연산은 연쇄 반응에 배정합니다. 복원 붓은 강화용 칸 반응 유물이며, 상시 유물은 합연산을 보정합니다.

| 유물 | 역할과 배치 |
|---|---|
| 되비추는 거울 | 자기 칸의 조건과 레벨 합으로 반복하는 곱연산 원천입니다. 한 번에 ×1.01을 적용하고 독립 연쇄 하나를 시작합니다. |
| 긴 거울 | 1×2칸 원천입니다. 두 칸의 이번 발동 횟수 중 최댓값을 쓰고 전체 외곽에서 전달합니다. 기본 배율은 작은 거울과 같은 ×1.01입니다. 두 칸이 모두 활성이고 요구 눈 묶음이 다를 때만 회당 ×1.02가 됩니다. |
| 금빛 동전 | 자기 칸 조건 없이 변 인접한 칸 원천의 실제 발동을 받아 +10을 만듭니다. 다른 연쇄 유물에서는 받지 않습니다. |
| 전시 도선 | 자기 칸의 눈 조건 없이 인접한 칸·연쇄 유물의 실제 발동을 받습니다. 감동 +4를 더하고 다음 유물로 이어 주므로 서로 떨어진 반응원을 연결하거나 조건이 어려운 칸을 중계 자리로 활용합니다. |
| 겹빛 렌즈 | 자기 칸의 눈 조건을 만족한 상태에서 인접 발동을 받습니다. 참여 한 번에 `+6 × 자기 칸의 구성 조각 수`를 얻습니다. 한 조각은 +6, 두 조각은 +12입니다. 칸의 레벨 합을 다시 곱하지 않습니다. |
| 행 관측자·계보의 인장 | 관측자는 같은 행의 칸 원천에서 +6을 받습니다. 인장은 하나의 같은 조각을 공유하는 유효 칸 원천이 둘 이상일 때 그 원천에서 +8을 받습니다. |
| 전시 받침대·긴 액자 | 받침대는 변 인접한 합연산에 +5, 액자는 긴 축과 같은 직선의 연쇄 합연산에 +4를 보정합니다. |

도선과 렌즈는 서로 연쇄를 전달할 수 있고, 같은 연쇄에 한 번만 참여합니다. 연결할 때 받는 쪽의 조건도 충족해야 하므로, 렌즈가 자기 조건을 만족하지 못하면 그 경로는 끊깁니다. 상시 유물은 발동 원천이 아닙니다.

- 칸의 조건은 겹친 조각의 고정 눈을 모두 요구하는 중복 허용 묶음입니다. 여러 세트가 나와도 추가 보상은 없습니다. 같은 주사위를 여러 칸의 조건에 사용할 수 있습니다.
- 조건을 만족한 칸은 구성 조각의 레벨 합만큼 발동합니다. 여러 칸 칸 반응 유물은 **점유 칸 중 최댓값**을 따릅니다. `[4,2]`와 `[4,0]`은 모두 4회입니다. 유물 전체가 하나의 원천이고 전체 외곽에서 전달하므로 칸별로 횟수나 연쇄를 중복 생성하지 않습니다.
- 작은 유물과 큰 유물의 기본 수치는 비슷하게 두고, 큰 유물에는 조건부 효과를 줍니다. 같은 수신 유물에 여러 변으로 닿아도 동일 연쇄에서는 한 번만 받습니다.
- 칸 유물의 매 발동이 독립 연쇄를 시작합니다. 각 연쇄에서 연쇄 유물은 한 번만 참여하며, 너비 우선 탐색(BFS)으로 전달합니다. 합류할 때는 대기열에 넣는 순간 참여를 확정합니다.
- 조각은 **런 전체에서 단 한 번만 Lv.1 → Lv.2로 강화**합니다. 강화 유물은 제출당 최대 한 번, 아직 강화하지 않은 조각마다 충전 1을 사용합니다. 부족하면 큰 조각부터, 크기도 같으면 무작위로 선택합니다. 다른 붓을 써도 같은 조각을 다시 강화할 수 없습니다.
- 강화할 조각이 없으면 붓은 발동하지 않고 충전을 보존하며 연쇄도 시작하지 않습니다. 상점에서 새 조각으로 붓을 옮겨 남은 충전을 활용합니다. 겹침 칸에서도 이미 강화한 조각은 제외합니다.
- 강화 레벨은 즉시 오르고, 발동 횟수 증가는 다음 제출부터 적용합니다. 마지막 충전으로도 효과와 연쇄를 처리한 후 유물이 사라집니다.
- 감동은 다섯 등급의 고정 팁으로 바뀝니다. 주차 배율은 관객·평가 기준에만 적용되며, 돈·가격은 고정입니다. 유물 판매는 구매가의 10%입니다.
- 주사위 면 개조는 특정 주사위의 특정 면 하나를 원하는 눈으로 바꿉니다. 중복 눈을 허용하며 이후 모든 굴림에 적용합니다.

## 프로토타입에서 정한 임시 해석

다음은 확정 기획의 변경이 아니라 실행 가능한 실험을 위한 선택입니다.

- 주사위는 5개, 각 주사위는 동일 확률의 면 6개입니다. 조각의 초기 레벨은 1입니다.
- 평가 기준과 정확히 같아도 통과합니다. 보스 주간은 2·4·6·8주이며, 추가 배율은 보스 주간 다음 주부터 적용합니다.
- 제출 순간의 배치·범위·상시 보정·조건 충족 여부를 해당 제출 동안 고정합니다. 강화 소멸로 같은 제출의 다른 연쇄 조건이 바뀌지 않습니다.
- 원천 유물과 같은 BFS 깊이의 처리 순서는 위→아래, 왼쪽→오른쪽입니다. 주사위·상점·강화 동률은 재현 가능한 시드 난수를 사용합니다.
- 여러 칸 강화 유물의 대상은 점유 영역 아래의 서로 다른 조각 전체입니다. 같은 조각은 중복 집계하지 않습니다. 같은 조각 공유는 유물 점유 칸 하나 이상이 그 조각에 속하면 인정합니다.
- 상시 보정은 여러 개면 더합니다. 유물은 서로 겹칠 수 없으며 상점에서 이동·회전할 수 있습니다. 이미 배치한 조각은 이동·판매하지 않습니다.
- 겹침으로 주사위 5개가 충족할 수 없는 조건도 만들 수 있습니다. 칸 반응과 렌즈는 이 조건을 충족하지 못하지만 자기 칸 조건을 요구하지 않는 도선은 전달받아 반응할 수 있습니다.
- 같은 원천의 반복 연쇄는 고정된 그래프에서 동일하므로 계산은 묶어서 처리합니다. 연쇄당 한 번이라는 규칙과 점수는 그대로이며, 화면에는 반복 횟수를 표시합니다.

## 검증

규칙 테스트는 실제 런의 승률을 검증하는 테스트와 구분합니다. 특히 8주 종료 테스트의 고레벨 상태는 종료 경로를 확인하기 위한 테스트 데이터입니다.

`simulate.mjs`는 공개 상태만 이용하는 자동 플레이어입니다. 실제 진행은 엔진의 합법 행동을 사용하고, 다음 난수나 미래 주사위를 미리 읽지 않습니다. 구매·배치·리롤 선택은 휴리스틱이므로 사람의 학습 난이도와 재미를 대변하지 않습니다. 설정·결과·재현 명령은 밸런스 보고서에 기록합니다.

현재 수치는 초기 플레이테스트용입니다. 확정 기획은 상위 폴더의 `기획서.md`를 참조합니다.

현재 규칙 버전은 4입니다. 이전 규칙으로 마친 런의 점수·레벨·클리어 기록과 당시 유물 효과 표시는 보존합니다. 진행 중인 이전 런은 Lv.2 상한과 새 점수 역할을 적용하고 메아리석→전시 도선, 종→겹빛 렌즈로 교체합니다. 이미 얻은 점수·배치·돈은 유지합니다. 진행 중 상점의 유료 조각과 일반 관객 뒤 조각 보상은 제거하며, 평가 통과 뒤 기존 조각 후보는 다시 뽑지 않고 유지합니다. 저장 슬롯은 `strange-museum-run-v4`이며 이전 v3·v2·v1 원본도 남습니다. 기존 동전은 이제 인접한 칸 원천이 필요하므로 상점에서 배치를 확인하세요. 새 균형을 비교할 때는 새 런을 시작하세요.

기존 450런 완주율, 강화 상한만 적용한 60런, 도선·렌즈 v3의 훈련 150런·미사용 검증 300런은 모두 이전 버전의 기록입니다. v4의 기능 검증은 [QA.md](QA.md)에 구분하며, 전체 런 균형과 인간 플레이는 별도 검증 대상입니다.

일반 관객 기본 기준은 70, 평가 담당자는 150이며 주간 배율은 1.46, 보스 직후 추가 배율은 1.30입니다. v3에서 이어 쓴 시험 값이며 v4 보상 주기·역할에 맞는 균형값으로 검증된 것은 아닙니다.

수치·실행 기록과 자동 플레이 결과는 [BALANCE.md](BALANCE.md)에 있습니다. `relay-diagnostics.json`은 동전이 칸 원천이던 v3 통제 비교이며, `overlap-diagnostics.json`의 Lv.5 이상 사례도 역사적 계산입니다. 새 실행으로 이 결과 파일을 덮어쓰지 않습니다. 다음 작업자는 상위 폴더의 [context.md](../context.md)에서 현재 규칙·코드 구조·실행·검증 상태를 확인할 수 있습니다.
