# 이상한 박물관

주사위를 나누어 내고 유물을 발동시켜 관객의 감동을 모으는 게임입니다. 매주 세 번째 관객은 평가 담당자입니다. 여덟 번째 주의 평가를 통과하면 클리어합니다.

## 열기

| 실행 방식 | 여는 방법 |
|---|---|
| 브라우저에서 바로 플레이 | [dist/play.html](dist/play.html)을 브라우저로 엽니다. Windows에서는 [PLAY.cmd](PLAY.cmd)를 더블클릭해도 됩니다. HTML 하나에 게임 전체가 들어 있습니다. |
| 로컬 서버 | Node.js가 있는 환경에서 저장소 루트의 터미널에 `node prototype/server.mjs`를 입력하고 출력된 주소를 엽니다. 기본 포트는 4173입니다. |
| 텍스트로 플레이 | 저장소 루트에서 `node prototype/cli.mjs --seed 42`를 실행하거나 Windows에서 [TEXT.cmd](TEXT.cmd)를 엽니다. `help`로 명령을 확인합니다. |

브라우저는 행동이 끝날 때 진행 상태를 자동 저장합니다. 같은 브라우저에서 같은 파일이나 서버 주소를 다시 열면 이어집니다. 화면 아래 저장 상태를 확인할 수 있습니다. 파일로 열었을 때 브라우저가 저장을 제한하면 로컬 서버로 실행하세요.

## 첫 관람

1. 첫 화면의 평가 일정에서 8주간 만날 보스와 벌칙을 확인하고 **첫 관객 맞이하기**를 누릅니다. 관람이 시작되면 관객의 기준, 주사위 여섯 개, 관람 뒤 무료로 고를 유물 세 개가 공개됩니다.
2. 남은 주사위를 눌러 하나 이상 고릅니다. 미리보기에서 일치하는 패턴, 발동할 유물, 토큰의 변화, 제출 뒤 예상 감동을 확인합니다. 선택을 바꾸거나 풀어도 주사위를 쓰지 않습니다.
3. **선택 제출**을 누르면 고른 주사위가 이번 관람에서 소모됩니다. 남은 주사위는 현재 눈을 유지합니다. **리롤**은 선택한 주사위만 다시 굴리며 관람당 기본 8회입니다.
4. 주사위를 전부 제출하거나 **조기 종료**를 누르면 관람 수명 토큰이 사라지면서 정산됩니다. 감동은 `합 × (1 + 배율)`입니다. 일반 관객은 기준에 못 미쳐도 다음으로 진행합니다. 평가 담당자의 기준에 못 미치면 런이 끝납니다.

처음 가진 **안내원**은 주사위 하나를 내면 나온 눈만큼 합을 올리고, **조명**은 같은 눈 둘을 내면 배율을 1 올립니다. 예를 들어 눈이 **2·2·4·4·5·6**이라면 2·2와 4·4를 각각 제출한 뒤 5와 6을 따로 제출해 보세요. 합 11, 배율 2로 감동은 **33**입니다. 여섯 개를 전부 한 번에 내면 이 두 유물은 발동하지 않습니다.

금고지기를 얻으면 같은 눈 둘로 그 주위에 동전을 놓을 수 있습니다. 동전 하나는 관람 끝에 합 5를 줍니다. 동전 가까이에 연금술사를 놓고 같은 눈 셋을 나중에 내면 인접 동전이 금괴로 바뀌어 하나당 합 15를 줍니다. 동전이 생기기 전후로 같은 눈 셋을 골라 미리보기의 차이를 확인할 수 있습니다.

관람 중 **자동 플레이**를 누르면 현재 관객의 정산까지 진행합니다. 개관 준비 또는 상점 화면의 **런 자동 진행**은 상점의 무료 선택·구매·배치까지 맡아서 런이 끝날 때까지 진행합니다. **자동 진행 멈추기**나 Esc로 정지한 뒤 직접 이어서 플레이할 수 있습니다.

## 전시 배치와 상점

| 하고 싶은 일 | 조작 |
|---|---|
| 유물과 토큰 조사 | 배치도의 유물이나 토큰을 누릅니다. 방향이나 인접 조건이 있는 유물은 대상 자리가 표시됩니다. 주사위 유물은 주변 대상 토큰 수와 요구량을 확인할 수 있습니다. |
| 배치도 이동·확대 | 빈 곳을 드래그해 이동합니다. 휠 또는 ＋·− 버튼으로 확대·축소하고 전체 보기 버튼으로 구매한 칸과 토큰을 다시 한눈에 봅니다. |
| 빈자리 조사·선택 | 마우스나 터치로 자리를 누릅니다. 배치도에 키보드 초점이 있으면 방향키로 좌표를 옮기고 Enter 또는 Space로 선택합니다. |
| 무료 유물과 진열 유물 받기 | 상점에서 원하는 유물을 고르고 구매한 빈칸을 눌러 배치합니다. 배치가 끝나야 돈이나 무료 선택권을 사용합니다. 무료 보상은 한 관람당 하나이며 거절할 수 있습니다. |
| 칸 구매 | 상점에서 칸 구매를 선택한 뒤 원하는 미구매 자리를 누릅니다. 첫 칸은 4원이며 구매할 때마다 가격이 2원씩 오릅니다. 떨어진 자리도 살 수 있습니다. |
| 유물 옮기기·회전·판매 | 상점에서 판의 유물을 눌러 **이동**을 선택하고 구매한 빈칸을 누르거나, 유물을 그 칸으로 드래그합니다. 방향 유물은 R 또는 **회전** 버튼으로 90도 회전합니다. Esc 또는 **취소**로 배치를 취소합니다. 유물 정보에서 판매하면 가격의 10%를 받습니다. |
| 평가와 연출 확인 | 상단의 **평가 일정**은 언제든 다시 볼 수 있습니다. 보스전에서는 예상 감동과 벌칙을 함께 확인하세요. 제출 연출은 건너뛸 수 있습니다. |

칸을 사도 그 위의 지속 토큰은 남습니다. 유물을 놓으려면 그 자리가 비어 있어야 합니다. 주사위 유물은 요구량보다 적은 토큰도 파괴하므로 제출 전에 미리보기 경고를 확인하세요. 주사위를 얻으면 다음 관람부터 굴립니다.

## 텍스트 조작

플레이 기록을 남겨 선택을 진단하려면 별도 디렉터리의 [텍스트판](../prototype_text/README.md)을 사용하세요. 같은 규칙 엔진으로 제출 순서 비교, 이어하기와 관객별 재생을 지원합니다.

| 명령 예시 | 기능 |
|---|---|
| `start`, `view`, `board`, `schedule`, `dice` | 관람 시작, 현재 상태, 판의 좌표 목록, 보스 일정, 영구 주사위 면 구성 |
| `preview 1 3`, `submit 1 3`, `roll 1 3` | 주사위 번호 1·3번을 미리보기, 제출, 리롤. 숫자는 주사위의 고유 번호입니다. |
| `end`, `auto` | 조기 종료, 현재 관람의 남은 행동 자동 진행 |
| `cell -1 2` | 좌표 (−1, 2)의 칸 구매 |
| `artifact free 2 1 1`, `artifact shop 1 -1 2 1` | 무료 보상 2번을 (1, 1)에 배치, 진열 1번을 (−1, 2)에 오른쪽 방향으로 배치 |
| `move 1 1 -1 2`, `rotate -1 2`, `sell -1 2` | (1, 1)에서 (−1, 2)로 이동, 해당 유물 회전, 판매 |
| `skip`, `next`, `catalog`, `quit` | 무료 보상 거절, 다음 관객 입장, 유물 목록, 텍스트 게임 종료 |

## 개발과 검증

아래 명령은 저장소 루트에서 실행합니다. 외부 패키지 설치 없이 Node.js 내장 기능을 사용합니다.

```sh
node --test "prototype/tests/*.test.cjs"
node prototype/simulate.mjs --runs 5 --seed 42
node prototype/build-standalone.mjs
```

시뮬레이션은 시작 시드부터 연속된 런을 진행하고, 주차별 도달률, 평가 후 주사위 수, 관객별 감동 분포를 출력합니다. 전체 결과는 `prototype/results/`에 새 JSON으로 기록합니다. `--out`으로 경로를 지정할 때는 새 파일명을 사용합니다. 웹 소스를 수정한 뒤 세 번째 명령을 실행하면 직접 여는 HTML에도 반영됩니다.

규칙은 [프로토타입 설계](../프로토타입_설계.md), 구현 결정은 [개발 문맥](../context.md), 실행 검증 결과는 [QA 기록](QA.md)에 있습니다. 이전 폴리오미노 버전의 실행 안내는 Git 커밋 `18cb9df`의 `prototype/README.md`에서 열 수 있습니다.
